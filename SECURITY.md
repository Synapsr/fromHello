# Security policy

This repository holds fromHello’s README, license and project files. The platform source isn’t published here yet, so there is no application code in it to assess.

When the platform source is published, this policy will gain supported versions and full disclosure details.

## Reporting a vulnerability

If you find a security issue in anything we publish, or in fromHello Cloud during early access, email **security@fromhello.io** with:

- a description of the issue and its impact
- steps to reproduce
- any relevant logs, requests or proof of concept

Please don’t open a public issue for security reports. We’ll acknowledge your report and keep you posted on the fix. Coordinated disclosure is welcome.
