# Contributing

Thanks for stopping by.

fromHello’s platform source isn’t published in this repository yet, so there’s no codebase to send pull requests to. A contribution guide (setup, architecture and conventions) will land with the source.

Until then, the most useful things you can do:

- **Join the waitlist** at [fromhello.io](https://fromhello.io/?utm_source=github&utm_medium=repo#waitlist). Early access comes in stages, with hands-on onboarding.
- **Star this repository** to help more teams find fromHello.

Once the code is here, contributions run the usual way: open an issue to discuss anything non-trivial first, keep pull requests focused, and match the surrounding style.
